GUIDE DU SITE · CONFIGURATION DANS L’APP

Connecte ton crew.

Telegram pour démarrer simplement. WhatsApp si tu disposes d’une configuration Meta Cloud API.

Cette page explique les étapes ; elle ne connecte rien.

Ouvre l’application Crewlo sur ton PC Windows pour saisir tes identifiants et confirmer l’appairage. L’aperçu dans un navigateur ne peut pas connecter les agents : le moteur Electron de l’application est nécessaire.

Avant de commencer

Garde le PC allumé, Crewlo ouvert et connecté à Internet. Dans ton studio, ouvre une session agent compatible avec la messagerie Crewlo, par exemple Claude Code ou Codex, déjà authentifiée et disponible. La messagerie réutilise cette session : elle ne crée pas un agent à ta place.

Tu n’as pas encore lancé l’app ? Voir le démarrage depuis les sources.

01

BOT API OFFICIELLE · SANS TUNNEL

Telegram

  1. Crée ton bot.

    Dans Telegram, ouvre le compte officiel @BotFather, envoie /newbot et suis ses instructions. Conserve le token reçu dans un endroit sûr. Documentation officielle BotFather.

  2. Connecte-le dans Crewlo.

    Dans l’app Windows, clique sur Telegram en haut à droite. Colle le token dans le champ secret prévu, puis clique sur Connect. Ne colle jamais ce token dans un chat, un terminal, une capture ou un ticket GitHub.

  3. Associe ton compte, puis confirme sur le PC.

    Ouvre le lien ou scanne le QR généré par Crewlo. Dans le chat privé du bot, appuie sur Start. Reviens sur le PC, vérifie ton nom et ton identifiant Telegram, puis clique sur Confirm pairing. Refuse toute identité inconnue. Le lien est à usage unique et expire après cinq minutes.

  4. Choisis un agent disponible.

    Sélectionne le Default agent dans Crewlo. Tu peux aussi envoyer /agents depuis Telegram, puis /agent <id> avec l’identifiant réellement affiché dans la liste.

  5. Fais un premier test sans risque.

    Envoie le texte ci-dessous. Attends une vraie réponse préfixée par le nom de l’agent, puis vérifie le même échange dans Conversation, avec son badge Telegram.

    Réponds simplement : Bonjour depuis Crewlo.

Aucun webhook public n’est nécessaire : Crewlo utilise le long polling. N’utilise pas simultanément le même bot avec un autre programme. Un webhook existant ou un second lecteur peut bloquer la connexion.

02

META CLOUD API · CONFIGURATION PLUS TECHNIQUE

WhatsApp

Ce n’est pas WhatsApp Web. Le QR Crewlo ouvre un message d’appairage vers un numéro Cloud API. Ce n’est pas le QR « Appareils connectés » de ton compte personnel.

  1. Prépare une application Meta et un numéro API.

    Configure WhatsApp Cloud API dans ton application Meta. Pour débuter, utilise le numéro de test fourni et ajoute ton téléphone aux destinataires de test autorisés. Récupère le Phone number ID, un access token avec les permissions WhatsApp nécessaires et l’App secret. Un token de test peut expirer ; Crewlo ne le renouvelle pas automatiquement.

  2. Renseigne le panneau WhatsApp dans Crewlo.

    Sur le PC, clique sur WhatsApp en haut à droite. Les champs se remplissent dans l’app, jamais sur cette page :

    Phone number ID
    L’identifiant Meta du numéro, pas ton numéro de téléphone.
    Access token
    Le token Meta autorisé pour ce numéro. Garde-le secret.
    App secret
    Le secret de ton application Meta, utilisé pour vérifier les signatures des webhooks.
    Verify token
    Un secret de ton choix : 24 à 128 lettres, chiffres, _ ou -. Conserve-le pour renseigner exactement la même valeur dans Meta.
    Graph API version
    La version utilisée par ton application Meta, au format vNN.N. Vérifie la valeur au lieu de choisir une version au hasard.
    Local port
    8788 par défaut ; choisis un port local libre si nécessaire.

    Clique ensuite sur Connect WhatsApp. L’état Local listener ready indique seulement que le récepteur local est prêt, pas que Meta atteint ton PC.

  3. Configure ton relais HTTPS et le webhook Meta.

    Avec ton propre tunnel ou relais, fais parvenir une URL HTTPS publique au récepteur local affiché par Crewlo. Par défaut :

    http://127.0.0.1:8788/whatsapp/webhook

    Dans Meta, indique l’URL publique de callback correspondant à ce chemin et le même Verify token. Termine la vérification, abonne-toi au champ messages et vérifie que l’application est abonnée au compte WhatsApp Business Account (WABA) concerné.

    Crewlo ne crée aucun tunnel automatiquement. Cette page n’ouvre aucun port public et ne fournit pas d’adresse de relais.

  4. Envoie le message d’appairage depuis ton téléphone.

    Ouvre le lien d’appairage wa.me ou scanne le QR affiché dans Crewlo. Envoie réellement le message prérempli au numéro Cloud API. Ouvrir le lien seul ne suffit pas. Reviens sur le PC, vérifie ton numéro et clique sur Confirm pairing. Le lien est à usage unique, valable cinq minutes.

  5. Choisis l’agent et vérifie une réponse réelle.

    Sélectionne le Default agent, ou envoie /agents puis /agent <id> dans WhatsApp. Envoie « Réponds simplement : Bonjour depuis Crewlo. ». Vérifie la réponse avec le nom de l’agent sur ton téléphone et dans Conversation, avec le badge WhatsApp.

Fenêtre de réponse : les réponses libres nécessitent un message utilisateur dans les dernières 24 heures. Si Crewlo affiche Waiting for your WhatsApp message, envoie un nouveau message depuis ton téléphone. Crewlo ne contourne pas cette limite avec des modèles payants.

UN ÉTAT AFFICHÉ N’EST PAS UNE PREUVE DE LIVRAISON

Le test est réussi quand…

  • La réponse réelle de l’agent arrive sur ton téléphone et dans Conversation.
  • Un autre compte ou un groupe ne déclenche aucun travail. Ne confirme aucune identité inconnue.
  • Une demande envoyée pendant Message delivery paused attend, puis part une seule fois après Resume sur le PC.
  • Une session agent indisponible est signalée honnêtement. La connexion au canal ne signifie pas que l’agent est prêt.

Accepted by WhatsApp

Meta a accepté la requête. Cela ne prouve pas que le téléphone a reçu le message. Delivered et Read dépendent des notifications de Meta.

Awaiting agent reply

Une réponse de l’agent manque encore. Vérifie sa session et ses éventuelles demandes de permission sur le PC. N’envoie pas la même demande en boucle.

Delivery uncertain

L’envoi a un résultat ambigu. Vérifie le téléphone et Conversation avant de renvoyer : Crewlo n’annonce pas une réussite qu’il ne peut pas confirmer.

Limite de la vérification actuelle : les tests locaux utilisent des API et réponses agent simulées. Ils ne valident pas ton token, ton application Meta, ton relais public ou ton modèle réel. La connexion de bout en bout reste à vérifier avec les étapes ci-dessus.

Les identifiants secrets utilisent le stockage chiffré du système. L’historique local de conversation n’est pas chiffré par cette fonctionnalité. Telegram, Meta et ton fournisseur IA conservent leurs propres règles de données et de coûts.
