SOURCE INSTALLATION

Start your first crew.

Prepare the app, connect one agent and try a small request. These steps run on your computer; this website cannot start an agent.

Early-stage source preview. No verified installer or release feed exists. Windows runtime checks are documented; a clean rebuild still depends on your toolchain. macOS and Linux runtime behavior remains unverified.

1. Requirements2. Build & open3. Connect an agent4. First mission

01 / PREPARE

Check your tools.

  • Git, Node.js 22.22 or newer, and npm.
  • Python 3 compatible with node-gyp for native dependency rebuilds.
  • On Windows: Visual Studio C++ build tools, Windows SDK, and matching MSVC Spectre-mitigated libraries.
  • Your chosen agent CLI, its account or credentials, and a project folder you are comfortable letting it access.

Clone the repository, then run the read-only diagnostic. If you already have a checkout, skip the first two lines.

PREPARE & CHECK
git clone https://github.com/HafidIdrissi/crewlo.git
cd crewlo
npm run doctor

Review these commands before running them.

Resolve diagnostic failures before proceeding. The doctor does not install anything, check Python compatibility or prove that a clean native rebuild will succeed. Missing dependencies before the first installation are expected. Detailed diagnostic notes (French).

02 / BUILD FROM SOURCE

Open the desktop app.

Once the prerequisites are ready, install dependencies and launch Crewlo. npm ci downloads dependencies and rebuilds native modules through the project’s postinstall script.

INSTALL & RUN
npm ci
npm run doctor
npm run dev

Run these from your Crewlo checkout after fixing prerequisites.

npm run dev opens the Electron app. npm run site only previews the website; it cannot run your agents.

Installation fails or the app will not open?
  • Node not found or too old: check node --version in a new terminal. Make sure the correct Node version is on PATH.
  • MSB8040: add the Spectre libraries matching your MSVC toolset version and architecture in Visual Studio Installer.
  • Missing SDK or compiler: install the Windows desktop C++ tools and SDK, then rerun the doctor.
  • Native module error: after correcting prerequisites, run npm run postinstall, then npm run doctor.

Existing native binaries passing a runtime check do not prove a clean rebuild. See known verification limits.

03 / CONNECT AN AGENT

Bring your own tools.

Complete onboarding. Install and authenticate the agent CLI you intend to use, then choose Add agent, give it a name, select the corresponding provider preset and choose its project folder.

Confirm the session is available before sending work. Provider presets and automated contracts do not certify every provider’s live behavior. Read the validation scope.

Your provider’s account, usage costs and permissions still apply. Review the CLI’s approval and automation settings before giving it access to a project.

04 / A SMALL FIRST MISSION

Ask. Watch. Read.

Open a familiar project and send a small request from the mission composer:

Read this project and explain what it does. Suggest one small improvement before changing any files.
  1. Check the delivery state. If it says Message delivery paused, use Resume on the desktop when ready.
  2. Follow the activity, then open the agent’s Conversation or terminal for context.
  3. Review any permission request in the app or CLI; behavior depends on your settings.
  4. Read the actual response. A queued or accepted message is not a completed task.

Pausing delivery does not stop a tool that is already running. Keep your computer and the agent session available.
