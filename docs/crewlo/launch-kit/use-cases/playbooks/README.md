# MVP workshops with Crewlo

[Explore use cases on the website](https://hafididrissi.github.io/Crewlo/use-cases.html) · [Download the ZIP kit](https://hafididrissi.github.io/Crewlo/crewlo/launch-kit/use-cases/playbooks/crewlo-playbooks-en.zip)

Each workflow explains which agents to create, which prompts to send, which files to hand over and how to verify the result through a usable local demonstration. All guides, prompts, agent setups and filming instructions are in English.

1. [Prepare the folder and create the three agents](GETTING-STARTED.en.md).
2. [TaskBoard: a task manager](01-taskboard.en.md).
3. [ClientFlow: a freelance CRM](02-clientflow.en.md).
4. [LaunchPage: a page and form connected to a local API](03-launchpage.en.md).
5. [Record the workflow and result](04-filming.en.md).

The [23 text prompts](prompts/) are also available separately. Import the three agent setup files through **Create agent → Advanced · import an agent setup**: [Product](agents/product.json), [Dev](agents/dev.json), [QA](agents/qa.json). Then choose your folder and connected engine in the form.

These are scenarios to execute. They do not present the applications as already built or validated by Crewlo. Previously shared French reader URLs redirect to the English guides.

## Edit or rebuild the kit

Markdown files are the authored sources. HTML pages, text prompts, JSON setup files and ZIP are generated by [tools/build-crewlo-playbooks.py](https://github.com/HafidIdrissi/Crewlo/blob/main/tools/build-crewlo-playbooks.py).

From the repository root, with Python and the `Markdown` module installed:

```sh
python tools/build-crewlo-playbooks.py
```

The generator does not open agent sessions or call providers. To preview the whole website, run `npm run site` and open `/use-cases.html` at the printed local address.
