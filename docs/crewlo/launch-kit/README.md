# Crewlo launch kit

English materials for presenting Crewlo. This repository contains draft copy and illustrated videos; committing these materials does not submit or schedule a launch on an external platform.

## Use cases and demos

[Website use-case page](https://hafididrissi.github.io/Crewlo/use-cases.html) · [Video gallery](use-cases/index.html) · [Detailed workshops](use-cases/playbooks/README.md).

The practical workshops cover TaskBoard, ClientFlow and LaunchPage, including three agent setups, 23 copyable English prompts and final acceptance checks. The illustrated videos include landscape, vertical and focused MVP formats with English on-screen text and subtitles. They do not show a live MVP build.

## Draft launch copy

- [DEV.to article](devto.md): article, four tags, illustration and AI-writing disclosure; `published: false`.
- [Product Hunt](product-hunt.md): tagline, description, first comment and gallery references.
- [Hacker News](hacker-news.md): Show HN title, repository URL and separate first comment.

Review the final text and current product status before publishing to any platform. Platform submission and scheduling are separate actions.
