FOUNDATIONS & DIFFERENCES

What belongs to Crewlo?

Crewlo is an independently maintained fork of Munder Difflin, by Chaitanya Giri and contributors. It retains the Electron, React, Pixi.js and xterm.js foundation, including agent sessions, orchestration, permissions, memory and task records.

Crewlo adds original procedural voxel artwork, its own visual identity, a responsive mission surface, activity labels derived from execution events, and paired-owner Telegram/WhatsApp transports that reuse existing sessions and delivery controls. The studio’s visual zones are not separate autonomous teams.

Engineering notes · Asset origins · MIT license · Third-party asset licenses

Local does not mean offline.

Workspace state is stored locally, but agent CLIs can send prompts and code to their AI providers. Telegram and Meta process messages through their platforms. Their data policies, subscriptions and API charges remain separate.

Messaging credentials use OS-encrypted storage, with no plaintext fallback. Conversation history is not encrypted by these integrations. Paired messaging reuses agent permissions; it cannot approve tools or resume paused delivery remotely.

Application analytics require a configured build-time key and can be disabled in Settings or with DO_NOT_TRACK. This landing page uses local assets and no analytics script. Telemetry contract · Privacy details.
