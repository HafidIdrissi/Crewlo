WHAT CREWLO ADDS

A studio with its own point of view.

Crewlo is an independently maintained fork of Munder Difflin. It keeps the underlying agent engine and adds:

  • Original voxel studio and figurine artwork
  • A responsive mission surface and execution-event activity labels
  • Paired-owner Telegram and WhatsApp transports with visible delivery states

Agent sessions, orchestration, memory and permissions build on the upstream foundation. Messaging validation varies by channel.

BEFORE YOU TRY IT

Can I download an installer?

Not yet. Crewlo is a source-first preview. Windows runtime checks are documented, but a clean install, signed packages and macOS/Linux runtime behavior need further validation. Read the source setup guide.

Which agents can I use?

Crewlo uses agent CLIs you install and authenticate separately. Presets in the code are not proof that every provider, permission flow or messaging scenario has been tested. Use an available session in the app and check the current validation scope.

What does it cost, and where does my data go?

Crewlo’s source is MIT-licensed. Your AI provider and messaging services may charge separately and process the data you send them. Local execution does not mean offline processing. Read the boundaries.

Can I use it when my computer is off?

No. Keep your computer, Crewlo, network connection and agent session running. Messaging does not host agents or remotely approve tools. WhatsApp also needs your own HTTPS relay.
